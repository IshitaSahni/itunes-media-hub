INTERPRETATION

Key Findings & Limitations

01

Observed Timing

React recorded slightly lower mean page-load and controlled rendering times in these runs. Small differences do not establish that one framework is inherently faster.

02

Application Size

Vanilla JavaScript had a substantially smaller measured HTML, CSS and JavaScript footprint. The React production build includes framework code and bundled dependencies.

03

Search & Caching

Repeated searches produced zero observed additional API requests in the collected runs, consistent with caching. Cold searches are affected by network conditions and differing API request parameters.

Methodology Notes

Browser benchmarks were collected using Playwright and Chromium. Controlled rendering used the same response fixture for both applications. Search measurements include live API variability.

Bundle measurements compare Vanilla source files with a React production build. Gzip values represent compressed file sizes, not measured network transfers.
