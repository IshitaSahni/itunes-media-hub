INTERPRETATION

Key Findings & Limitations

01

Observed Timing

React recorded slightly lower average loading and controlled render-completion times in this test environment. Small differences do not establish that one framework is inherently faster.

02

Application Size

Vanilla JavaScript had a substantially smaller measured HTML, JavaScript and CSS footprint. React's production bundle includes framework code and bundled dependencies.

03

Search & Caching

Repeated searches generated no observed additional iTunes search requests in the collected runs, consistent with caching. Live network conditions affect cold-search timings.

Methodology Notes

Benchmarks use Playwright with Chromium. Search timing includes live API variability, while controlled rendering uses the same response fixture for both applications. Bundle sizes compare Vanilla source files with a React production build; estimated Gzip values are not measured network transfers.
